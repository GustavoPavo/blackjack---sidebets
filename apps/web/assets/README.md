# Recursos de marca — PROVISÓRIOS

Ícone e tela de abertura **provisórios**, desenhados para este projeto (ficha com "21" sobre feltro). Não há decisão de marca:
**substitua por identidade definitiva antes de qualquer publicação.** Nenhum recurso de terceiros foi usado (ver `docs/ASSETS.md`).

- `source/*.svg`: fontes editáveis.
- `icon-only.png` (1024², iOS), `icon-foreground.png` + `icon-background.png` (Android adaptativo), `splash.png` / `splash-dark.png` (2732²).
- Gerar os PNGs das plataformas a partir destes: `npm run assets:generate -w @bj/web` (usa `@capacitor/assets`).
